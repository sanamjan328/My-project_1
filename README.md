In 2019, I contributed to the MOBITEK project, a European Union and Turkish Ministry of Industry and Technology–funded initiative designed to strengthen digital infrastructure for Turkey’s furniture industry. My primary contribution was the development of an image search API capable of retrieving visually similar furniture items from a database of over 50,000 images.

To achieve this, I built a Deep Neural Network (DNN) pipeline combined with Support Vector Machine (SVM) classifiers for efficient image classification. Additionally, I implemented an image ranking mechanism based on distance metrics to facilitate accurate and rapid image retrieval. The project utilized Python and OpenCV technologies, focusing on scalable performance and robust preprocessing pipelines. This experience enhanced my practical understanding of computer vision applications, feature extraction, and the operationalization of AI solutions for industrial innovation.
